# js-todo-dom-ls

An employee records page. Fill in a person's name, id, department, experience, email, and mobile number. The table adds a row and gives them a role. Refresh the page and the rows are still there. Delete removes one row.

Experience sets the role. More than 5 years is Senior, 2 to 5 years is Junior, and 1 year or less is Fresher. The records stay in this browser only.

## How to open

From this folder, run:

```bash
npx --yes serve -l 5000 .
```

This starts a small local server. Then open http://localhost:5000/ .

You can also open `index.html` directly in a browser.
